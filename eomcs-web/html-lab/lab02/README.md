## 1. VSCode의 Emmet

### Emmet이란?

Emmet은 짧은 약어를 HTML이나 CSS 코드로 확장해 주는 코드 작성 도구이다. VS Code에 기본으로 포함되어 있으므로 별도의 확장을 설치할 필요가 없다.

예를 들어 `p{안녕하세요}`를 입력하고 Emmet으로 확장하면 다음 코드가 만들어진다.

```html
<p>안녕하세요</p>
```

Emmet은 코드를 생성하는 기능이다. 이미 작성된 코드의 들여쓰기와 줄바꿈을 정리하는 **문서 서식 지정(Format Document)**과는 역할이 다르다.

### HTML 기본 구조 만들기

1. `lab02/exam01.html` 파일을 생성한다.
2. VS Code 오른쪽 아래의 언어 모드가 **HTML**인지 확인한다.
3. 빈 HTML 파일에서 `!`를 입력하고 Emmet으로 확장하면 HTML 문서의 기본 구조가 생성된다.
4. 생성된 코드에서 문서 언어를 `ko`로, 제목을 `자기소개`로 수정한다. 결과는 다음과 같은 형태이다.
    ```html
    <!DOCTYPE html>
    <html lang="ko">
    <head>
      <meta charset="UTF-8">
      <meta name="viewport" content="width=device-width, initial-scale=1.0">
      <title>자기소개</title>
    </head>
    <body>

    </body>
    </html>
    ```

이후의 약어 예제는 `<body>`와 `</body>` 사이에서 입력하고 확장한다.

### 약어 입력하고 확장하기


1. `<body>`와 `</body>` 사이에 `p`를 입력한다. `<p>`가 아니라 태그 이름만 입력한다.
4. 자동 완성 목록에서 **Emmet Abbreviation**으로 표시된 항목을 선택하고 `Enter`를 누른다.
5. 생성된 `<p></p>` 안에 문단 내용(예: `안녕하세요. 홍길동입니다.`)을 입력한다.

자동 완성 목록이 나오지 않으면 `F1`을 누르고 `Emmet`을 검색한 뒤 **Emmet: Expand Abbreviation(약어 확장)** 명령을 실행한다. 이때 커서는 입력한 약어 바로 뒤에 둔다.

`Tab` 키로 약어를 확장하려면 VS Code 설정에서 `emmet.triggerExpansionOnTab`을 검색하여 활성화한다. 그러면 약어를 입력한 뒤 `Tab`을 눌러 확장할 수 있다. [VS Code Emmet 공식 안내](https://code.visualstudio.com/docs/languages/emmet)


### 자주 사용하는 약어 문법

| 문법 | 의미 | 입력 예 |
| --- | --- | --- |
| 태그 이름 | 요소 생성 | `p` |
| `{내용}` | 요소 안에 텍스트 삽입 | `h1{자기소개}` |
| `+` | 같은 부모 아래에 형제 요소 생성 | `h1+p` |
| `>` | 요소 안에 자식 요소 생성 | `div>p` |
| `*숫자` | 요소 반복 생성 | `p*3` |
| `$` | 반복할 때 순서 번호 삽입 | `p{문단 $}*3` |
| `#이름` | id 속성 지정 | `h1#title` |
| `.이름` | class 속성 지정 | `p.description` |
| `[속성="값"]` | 속성과 값 지정 | `a[href="https://example.com"]{사이트 방문}` |
| `()` | 여러 요소를 하나의 그룹으로 묶음 | `(h2+p)*2` |

`+`, `>`, `*` 등의 연산자 앞뒤에는 공백을 넣지 않는다. 텍스트 안의 공백은 `p{안녕하세요 반갑습니다}`처럼 중괄호 안에 작성한다. [Emmet 약어 문법](https://docs.emmet.io/abbreviations/syntax/)

### 예제 1: 제목과 문단 생성하기

입력:

```text
h1{자기소개}+p{안녕하세요. 홍길동입니다.}
```

확장 결과:

```html
<h1>자기소개</h1>
<p>안녕하세요. 홍길동입니다.</p>
```

`+`를 사용했으므로 `h1`과 `p`가 나란히 생성된다. `p`가 `h1` 안에 들어가는 것은 아니다.

### 예제 2: 자식 요소와 반복 사용하기

입력:

```text
div>p{문단 $}*3
```

확장 결과:

```html
<div>
  <p>문단 1</p>
  <p>문단 2</p>
  <p>문단 3</p>
</div>
```

`>`는 `div` 안에 `p`를 만들고, `*3`은 `p`를 세 번 반복한다. `$`는 반복할 때 1부터 증가하는 번호로 바뀐다.

### 예제 3: 속성 지정하기

입력:

```text
p#intro.description{저를 소개합니다.}
```

확장 결과:

```html
<p id="intro" class="description">저를 소개합니다.</p>
```

`id`는 문서 안에서 요소를 식별하는 이름이며 같은 값을 중복해서 사용하지 않는다. `class`는 여러 요소에 공통으로 지정할 수 있는 분류 이름이다. 이름을 붙이는 것만으로 화면의 색상이나 모양이 바뀌지는 않는다.

### 실습: 자기소개 내용 작성하기

1. `!`로 HTML 기본 구조를 만들고 문서 언어와 제목을 수정한다.
2. `body` 안에서 다음 약어를 입력하고 확장한다.

   ```text
   h1{나의 자기소개}+h2{나는 누구인가요?}+p{이름과 관심 분야를 작성하세요.}+h2{학습 목표}+p{HTML로 만들고 싶은 페이지를 작성하세요.}
   ```

3. 생성된 문단을 자신의 소개와 학습 목표로 바꾼다.
4. 파일을 저장하고 Live Preview에서 결과를 확인한다.
5. 생성된 코드에서 제목과 문단이 모두 `body`의 자식 요소인지 확인한다.

Emmet으로 생성한 뒤에도 태그와 속성을 직접 수정할 수 있다. 약어를 외우는 것과 함께 **생성된 HTML의 구조를 읽는 연습**을 한다.

## 2. HTML 기본 구조

HTML 문서는 `<html>` 요소로 시작하고 끝난다. `<head>`와 `<body>`는 `<html>`의 자식 요소이다. `<head>`에는 문서의 제목과 문자 인코딩, 스타일 시트, 스크립트 등 문서에 대한 정보를 넣는다. `<body>`에는 실제 화면에 표시되는 내용을 넣는다.

```html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>자기소개</title>
</head>
<body>
  <p>안녕하세요. 홍길동입니다.</p>
</body>
</html>
```

### `<!DOCTYPE html>`: HTML 문서 선언

- 브라우저가 문서를 표준 모드로 해석하도록 하는 선언이다.
- HTML 문서의 맨 앞에 작성한다.
- HTML 요소가 아니므로 닫는 태그를 작성하지 않는다.

### `<html lang="ko">`: 문서의 루트 요소

- `html`은 다른 HTML 요소를 감싸는 최상위 요소이다.
- 그 안에 문서 정보를 담는 `head`와 본문을 담는 `body`를 작성한다.
- `lang="ko"`는 문서의 기본 언어가 한국어임을 나타낸다. 화면 낭독기 등이 적절한 언어로 내용을 읽는 데 활용한다.
- `lang`은 언어를 지정하는 속성이며, 문자 인코딩을 지정하거나 내용을 한국어로 번역하는 기능은 아니다.

### `<head>`: 문서에 대한 정보

- 문서 제목, 문자 인코딩, 화면 표시 설정 등 문서에 대한 정보를 담는다.
- 이 예제의 `head` 내용은 웹 페이지의 본문으로 표시되지 않는다.
- CSS 파일을 연결하거나 JavaScript를 지정하는 요소도 넣을 수 있다.

### `<meta>`: HTML 문서에 대한 부가 정보(메타데이터)를 제공

#### 문자 인코딩: charset

```html
<meta charset="UTF-8">
```

- 브라우저에 문서를 UTF-8 문자 인코딩으로 해석하도록 알린다.
- UTF-8은 한글, 영문 등 다양한 문자를 표현할 수 있는 문자 인코딩이다.
- HTML 파일도 실제로 UTF-8로 저장해야 한다. 선언만 바꾼다고 파일의 저장 인코딩이 바뀌지는 않는다.
- 브라우저가 일찍 확인할 수 있도록 `head`의 앞부분에 작성한다.
- `meta`는 자식 내용과 닫는 태그가 없는 **빈 요소(void element)**이다. `</meta>`를 작성하지 않는다.

#### 문서 정보: `name`과 `content`

`name`(정보의 종류)과 `content`(그 정보의 값)를 사용하여 문서를 설명한다.

```html
<meta name="description" content="HTML 기초를 배우는 실습 페이지입니다.">
<meta name="author" content="홍길동">
```

- `description`: 문서의 요약 설명. 검색 엔진이 검색 결과의 설명문으로 활용할 수 있다.
- `author`: 문서 작성자

#### 모바일 화면 설정: `viewport`

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

- `width=device-width`: 레이아웃에 사용하는 뷰포트 너비를 기기의 화면 너비에 맞춘다. 이때 너비는 CSS 픽셀 기준이다. 즉 기기의 실제 화면 너비(물리적 해상도)가 아니라 CSS 픽셀로 환산한 너비(논리적 해상도)를 사용한다.
- `initial-scale=1.0`: 페이지를 처음 표시할 때의 확대·축소 비율을 1로 설정한다.
- 모바일 브라우저에서 페이지가 넓은 데스크톱 화면 기준으로 축소되어 표시되는 것을 방지하는 데 사용한다. 화면 크기에 따라 배치를 바꾸려면 CSS도 함께 작성해야 한다.

#### 특정 처리 지시: `http-equiv`

```html
<meta http-equiv="refresh" content="5">```
```

- 브라우저에 5초 후 페이지를 새로 고치도록 지시한다.
- 일부 HTTP 헤더와 유사한 처리 지시를 문서에 작성하는 방식이다.

### `<title>자기소개</title>`: 문서 제목

- 문서의 제목을 `자기소개`로 지정한다.
- 브라우저 탭이나 창의 제목 등에 사용된다.
- 페이지 본문에 제목을 표시하려면 `body` 안에 `h1` 등의 요소를 따로 작성한다.

### `<body>`: 페이지 본문

- 사용자가 웹 페이지에서 보게 될 내용을 담는다.
- 제목, 문단, 이미지, 링크, 표, 입력 폼 등을 작성한다.
- 이 예제에서는 `p` 요소 하나가 본문에 들어 있다.

### `<p>안녕하세요. 홍길동입니다.</p>`: 문단

- `p`는 하나의 문단을 나타내는 요소이다.
- `<p>`는 시작 태그이고, `</p>`는 종료 태그이다.
- 두 태그 사이의 `안녕하세요. 홍길동입니다.`가 문단의 내용이다.
- 브라우저는 이 텍스트를 페이지 본문에 표시한다.

### 요소의 포함 관계

```text
html
├── head
│   ├── meta (문자 인코딩)
│   ├── meta (뷰포트)
│   └── title
└── body
    └── p
```

- `head`와 `body`는 `html`의 자식 요소이며 서로 형제 관계이다.
- `p`의 부모 요소는 `body`이다.
- 요소를 중첩할 때는 안쪽 요소를 먼저 닫는다. 이 예제에서는 `</p>` → `</body>` → `</html>` 순서이다.
- 들여쓰기를 사용하면 이러한 포함 관계를 쉽게 읽을 수 있다.

## 3. 제목과 문단: `h1`~`h6`, `p`

### 제목의 수준 표현하기: `h1`~`h6`

`h1`부터 `h6`까지는 본문에서 제목을 나타내는 요소이다. `h`는 heading을 뜻하며, 숫자는 제목의 수준을 나타낸다.

| 요소 | 의미 | 자기소개 페이지의 예 |
| --- | --- | --- |
| `h1` | 가장 높은 수준의 제목 | 홍길동의 자기소개 |
| `h2` | 주요 주제의 제목 | 관심 분야 |
| `h3` | 주요 주제 안의 하위 제목 | 웹 개발 |
| `h4` | `h3` 주제 안의 하위 제목 | 프런트엔드 |
| `h5` | `h4` 주제 안의 하위 제목 | HTML 학습 |
| `h6` | `h5` 주제 안의 하위 제목 | 제목 요소 연습 |

여섯 수준을 모두 사용할 필요는 없다. 짧은 자기소개 페이지라면 `h1`과 `h2`, 필요한 경우 `h3` 정도로 구성할 수 있다.

### 문단 표현하기: `p`

`p` 요소는 하나의 문단을 나타낸다. 시작 태그 `<p>`와 종료 태그 `</p>` 사이에 문단의 내용을 작성한다.

### 줄바꿈과 수평선: `br`, `hr`

- `br`은 줄바꿈을 나타내는 빈 요소이다. 문단 안에서 줄을 바꾸고 싶을 때 사용한다.
- `hr`은 수평선을 나타내는 빈 요소이다. 문단과 문단 사이를 구분할 때 사용한다.

### 실습

1. `lab02/exam02.html` 파일을 생성한다.
2. 빈 HTML 파일에서 `!`를 입력하여 Emmet으로 HTML 문서의 기본 구조가 생성한다.
3. 다음 코드를 HTML 문서의 `body` 안에 작성한다.

```html
<h1>홍길동의 자기소개</h1>
<p>
  안녕하세요.<br>
  웹 개발을 공부하는 홍길동입니다.
</p>

<hr>

<h2>관심 분야</h2>
<p>웹 개발과 사진 촬영에 관심이 있습니다.</p>

<h3>웹 개발</h3>
<p>HTML로 문서의 구조를 만드는 방법을 배우고 있습니다.</p>

<h3>사진 촬영</h3>
<p>여행 중에 만나는 풍경을 사진으로 남기는 것을 좋아합니다.</p>

<hr>

<h2>학습 목표</h2>
<p>나를 소개하는 웹사이트를 직접 만들고 싶습니다.</p>
```

이 문서의 제목 구조는 다음과 같다.

```text
홍길동의 자기소개 (h1)
├── 관심 분야 (h2)
│   ├── 웹 개발 (h3)
│   └── 사진 촬영 (h3)
└── 학습 목표 (h2)
```

- `관심 분야`와 `학습 목표`는 같은 수준의 주제이므로 둘 다 `h2`를 사용한다.
- `웹 개발`과 `사진 촬영`은 `관심 분야`의 하위 주제이므로 `h3`를 사용한다.
- 위 그림은 **내용의 계층**을 나타낸다. 예제 코드의 `h1`, `h2`, `h3`, `p`는 모두 `body`의 직접 자식 요소이다.
- 제목의 수준을 표현하기 위해 `<h1><h2>...</h2></h1>`처럼 제목 요소 안에 다른 제목 요소를 넣지 않는다.

### 글자 크기보다 내용의 구조를 기준으로 선택하기

브라우저는 기본 스타일에서 제목을 굵게 표시하고 수준에 따라 크기와 여백을 다르게 적용한다. 그러나 `h1`~`h6`의 목적은 **문서의 제목 계층을 표현하는 것**이다.

- 글자를 작게 보이게 하려고 `h1` 다음에 `h4`를 선택하지 않는다.
- 일반 문장을 크게 보이게 하려고 제목 요소로 바꾸지 않는다.
- 글자 크기, 색상, 여백 등의 모양은 CSS로 조정한다.

제목 수준은 화면 낭독기 사용자가 문서 구조를 파악하고 원하는 제목으로 이동하는 데도 활용된다.

### 제목 수준을 정하는 기준

- 페이지 전체를 대표하는 `h1`을 하나 작성한다.
- 주요 주제에는 `h2`, 그 안의 하위 주제에는 `h3`를 사용한다.
- 하위 주제로 내려갈 때는 `h2`에서 바로 `h4`로 건너뛰지 않고 순서대로 정한다.
- 하위 주제의 설명이 끝나면 상위 수준으로 돌아갈 수 있다. 예제의 `h3` 다음에 새 주요 주제를 나타내는 `h2`가 나오는 것은 자연스럽다.
- 제목에는 해당 부분의 내용을 알 수 있는 구체적인 문구를 작성한다.

### `title`과 `h1`의 차이

| 구분 | `title` | `h1` |
| --- | --- | --- |
| 작성 위치 | `head` 안 | `body` 안 |
| 역할 | 문서의 제목 지정 | 본문의 최상위 제목 표현 |
| 표시 위치 | 브라우저 탭이나 창 제목 등 | 웹 페이지 본문 |

```html
<head>
  <title>홍길동의 자기소개</title>
</head>
<body>
  <h1>홍길동의 자기소개</h1>
</body>
```

위 코드는 두 요소의 위치를 비교하기 위한 일부 코드이다. 두 제목의 문구는 같아도 되지만, 한쪽을 수정한다고 다른 쪽이 자동으로 바뀌지는 않는다.

## 4. 인라인 태그: `strong`, `em`, `b`, `i`, `span`

문장 안의 일부 텍스트에 의미를 부여하거나 스타일을 적용할 때 사용한다. 기본적으로 요소 앞뒤에서 줄이 바뀌지 않고 문장의 흐름을 유지한다.

- `strong`: 중요성, 심각성, 긴급성을 나타낸다. 기본 스타일은 굵게 표시한다.
- `em`: 문장에서 힘주어 강조하는 부분을 나타낸다. 기본 스타일은 기울임꼴로 표시한다.
- `b`: 중요성을 추가하지 않고 핵심 단어처럼 주의를 끌 부분을 나타낸다. 기본 스타일은 굵게 표시한다.
- `i`: 전문 용어, 외국어 표현, 속마음처럼 일반적인 문장과 구별되는 부분을 나타낸다. 기본 스타일은 기울임꼴로 표시한다.
- `span`: 의미를 나타내지 않는 인라인 요소이다. 스타일을 적용하거나 스크립트로 제어할 때 사용한다. 기본 스타일은 없다.

### 실습: 자기소개 문장에 인라인 태그 적용하기

1. `lab02/exam03.html` 파일을 생성한다.
2. 다음 코드를 HTML 문서의 `body` 안에 작성한다.

```html
<h1>홍길동의 자기소개</h1>
<p>
  안녕하세요. 웹 개발을 공부하는
  <span style="color: royalblue;">홍길동</span>입니다.
</p>

<h2>관심 분야</h2>
<p>요즘 배우는 기술은 <b>HTML</b>, <b>CSS</b>, <b>JavaScript</b>입니다.</p>
<p>
  사용자에게 보이는 화면을 만드는
  <i lang="en">front-end</i> 개발에 관심이 있습니다.
</p>

<h2>학습 목표</h2>
<p><strong>기초를 탄탄하게 익히는 것이 가장 중요합니다.</strong></p>
<p>배운 내용은 예제 코드를 <em>직접</em> 작성하며 연습하겠습니다.</p>
```

- `strong`은 학습에서 중요하게 여기는 내용을, `em`은 문장에서 특히 힘주어 말하는 `직접`을 표시한다.
- `b`는 기술 이름을 핵심 단어로 눈에 띄게 하고, `i`는 영어 전문 용어를 주변 문장과 구별한다. `lang="en"`은 해당 부분의 언어가 영어임을 나타낸다.
- `span`은 이름 부분을 묶는다. 파란색은 `style` 속성에 작성한 CSS `color: royalblue;`가 적용한 결과이다. `style` 속성을 지우면 일반 텍스트와 같은 모양으로 표시된다.
- `strong`과 `b`, `em`과 `i`는 기본 모양이 비슷해도 의미가 다르므로 내용에 맞게 선택한다.
- 코드에서 문장을 여러 줄로 작성해도 그 위치에서 화면의 줄이 바뀌지는 않는다. 화면 너비에 따라 자동으로 줄이 바뀌며, 특정 위치에서 줄을 바꾸려면 `br`을 사용한다.

## 5. 텍스트 관련 태그

앞에서 배운 제목, 문단, 강조 요소 외에도 인용문, 코드, 수정 내역 등 텍스트의 성격을 나타내는 요소가 있다. 화면에 보이는 모양뿐 아니라 **내용의 의미에 맞는 태그**를 선택한다.

### 인용문: `blockquote`, `q`, `cite`

- `blockquote`: 다른 출처에서 가져온 긴 인용문을 별도 영역으로 나타낸다. 기본 스타일에서 들여쓰기가 적용되지만, 단순히 여백을 만들기 위해 사용하지 않는다.
- `q`: 문장 안의 짧은 인용문을 나타낸다. 브라우저가 일반적으로 인용 부호를 붙여 표시한다.
- `cite`: 책, 영화, 글 등 저작물의 제목을 나타낸다. 사람 이름만 표시하는 용도로 사용하지 않는다.

```html
<p>강사는 <q>태그의 모양보다 의미를 먼저 생각하세요.</q>라고 설명했다.</p>

<blockquote>
  <p>매일 배운 내용을 작은 예제로 만들어 확인해 보세요.</p>
</blockquote>
<p>출처: <cite>HTML 학습 안내서</cite> (실습용 가상 자료)</p>
```

인용문의 출처 URL을 나타내려면 `blockquote`나 `q`에 `cite` 속성을 사용할 수 있다. 이 속성은 화면에 출처 링크를 자동으로 표시하지 않는다. **`cite` 요소와 `cite` 속성은 역할이 다르다.**

### 코드와 공백 유지: `code`, `pre`

- `code`: 컴퓨터 코드의 일부를 나타낸다. 기본 스타일은 고정폭 글꼴이다.
- `pre`: 공백과 줄바꿈을 유지해야 하는 미리 서식화된 텍스트를 나타낸다.
- 여러 줄의 코드는 보통 `pre` 안에 `code`를 넣어 작성한다. `code`만으로는 줄바꿈과 연속 공백이 유지되지 않는다.

```html
<p>문단은 <code>&lt;p&gt;</code> 요소로 작성합니다.</p>

<pre><code>&lt;h1&gt;자기소개&lt;/h1&gt;
&lt;p&gt;안녕하세요.&lt;/p&gt;</code></pre>
```

브라우저의 코드 영역에는 다음 텍스트가 표시된다. 실제 제목과 문단 요소가 생성되는 것은 아니다.

```text
<h1>자기소개</h1>
<p>안녕하세요.</p>
```

`pre` 안에서도 HTML 태그는 해석된다. 따라서 태그 자체를 보여 주려면 `<` 등을 문자 참조로 작성해야 한다. 또한 코드 정렬을 위해 넣은 들여쓰기도 화면에 반영되므로 불필요한 공백을 넣지 않는다.

### 특수 문자 표시: 문자 참조

문자 참조는 태그가 아니라, HTML에서 특정 문자를 표현하는 표기법이다.

| 표기 | 표시되는 문자 | 사용 예 |
| --- | --- | --- |
| `&lt;` | `<` | 태그의 시작 기호를 텍스트로 표시 |
| `&gt;` | `>` | 태그의 끝 기호를 텍스트로 표시 |
| `&amp;` | `&` | 앰퍼샌드 표시 |
| `&quot;` | `"` | 큰따옴표 표시 |
| `&nbsp;` | 줄바꿈되지 않는 공백 | 두 단어 사이에서 줄이 나뉘지 않도록 함 |
| `&copy;` | © | 저작권 기호 표시 |

일반 텍스트의 연속 공백과 줄바꿈은 기본적으로 하나의 공백처럼 처리된다. 간격을 벌리려고 `&nbsp;`를 반복하기보다 CSS의 여백 속성을 사용한다.

### 사용자 입력과 출력 결과: `kbd`, `samp`

- `kbd`: 키보드 입력 등 사용자가 입력해야 하는 내용을 나타낸다.
- `samp`: 프로그램이나 시스템의 출력 결과를 나타낸다.

```html
<p>저장하려면 <kbd>Ctrl</kbd> + <kbd>S</kbd>를 누르세요.</p>
<p>macOS에서는 <kbd>Command</kbd> + <kbd>S</kbd>를 누르세요.</p>
<p>실행 결과: <samp>Hello, HTML!</samp></p>
```

두 요소는 기본적으로 고정폭 글꼴로 표시될 수 있다. 키보드 키처럼 테두리를 그려 주는 모양은 CSS로 추가한다.

### 표시와 수정 내역: `mark`, `del`, `ins`, `s`

| 요소 | 의미 | 일반적인 기본 표시 |
| --- | --- | --- |
| `mark` | 현재 문맥에서 관련이 있어 눈여겨볼 부분. 예: 검색 결과의 검색어 | 배경색 강조 |
| `del` | 문서에서 삭제한 내용 | 취소선 |
| `ins` | 문서에 추가한 내용 | 밑줄 |
| `s` | 더 이상 정확하거나 유효하지 않은 내용 | 취소선 |

```html
<p>검색 결과: 오늘은 <mark>HTML</mark>의 텍스트 요소를 배웁니다.</p>
<p>수업 시간 변경: <del>오전 9시</del> <ins>오전 10시</ins></p>
<p><s>현재 신청할 수 있습니다.</s> 신청이 마감되었습니다.</p>
```

- `mark`는 검색어처럼 현재 문맥과의 관련성을 표시한다. 내용 자체의 중요성을 나타내는 `strong`과 구분한다.
- `del`과 `ins`는 문서의 편집 내역을 표현한다. 단순히 더 이상 유효하지 않은 안내는 `s`로 표현할 수 있다.
- 밑줄이나 취소선 모양만 필요하다면 CSS를 사용한다.

### 부가 설명과 첨자: `small`, `sub`, `sup`

- `small`: 저작권, 주의 사항 등 짧은 부가 설명을 나타낸다. 단순히 모든 글자를 작게 만드는 용도로 사용하지 않는다.
- `sub`: 화학식 등에서 아래 첨자를 나타낸다.
- `sup`: 거듭제곱 등에서 위 첨자를 나타낸다.

```html
<p>물의 화학식은 H<sub>2</sub>O입니다.</p>
<p>정사각형의 넓이는 한 변의 길이가 a일 때 a<sup>2</sup>입니다.</p>
<p><small>&copy; 2026 홍길동. 실습용 페이지입니다.</small></p>
```

### 약어: `abbr`

`abbr`는 약어나 두문자어를 나타낸다. `title` 속성으로 전체 표현을 제공할 수 있다.

```html
<p>
  <abbr title="HyperText Markup Language">HTML</abbr>은
  웹 문서의 구조를 표현하는 마크업 언어입니다.
</p>
```

일부 브라우저에서는 마우스를 올리면 `title`의 내용이 표시된다. 터치 화면 등에서는 확인하기 어려울 수 있으므로, 독자가 꼭 알아야 하는 설명은 본문에도 작성한다.

### 실습: HTML 학습 메모 작성하기

1. `lab02/exam04.html` 파일을 생성하고 Emmet의 `!`로 기본 구조를 만든다.
2. `lang`을 `ko`로, 문서 제목을 `HTML 학습 메모`로 수정한다.
3. 다음 코드를 `body` 안에 작성한다.

```html
<h1>HTML 학습 메모</h1>

<h2>오늘 배운 내용</h2>
<p><mark>HTML</mark>은 웹 문서의 구조를 표현하는 언어입니다.</p>
<p>문단을 작성하려면 <code>&lt;p&gt;</code> 요소를 사용합니다.</p>

<h2>예제 코드</h2>
<pre><code>&lt;h1&gt;나의 첫 페이지&lt;/h1&gt;
&lt;p&gt;반갑습니다.&lt;/p&gt;</code></pre>

<h2>실습 안내</h2>

<p><small>&copy; 2026 홍길동. HTML 수업 실습 자료입니다.</small></p>
```

## 6. 블록 요소와 인라인 요소

### 화면에 배치되는 방식

HTML 요소는 브라우저의 기본 스타일에 따라 서로 다른 방식으로 배치된다. 대표적인 방식은 **블록(block)** 과 **인라인(inline)** 이다.

- **블록 요소**는 일반적인 문서 흐름에서 새 줄에 배치된다.
- **인라인 요소**는 문장 안에서 텍스트와 함께 배치되며, 요소가 시작한다는 이유만으로 새 줄로 내려가지 않는다.

이 구분은 주로 CSS의 `display` 속성에 따른 **배치 방식**을 설명한다. HTML 요소의 의미나 어떤 요소를 자식으로 넣을 수 있는지를 모두 결정하는 규칙은 아니다.

### 블록 요소

대표적으로 `h1`~`h6`, `p`, `div`, `blockquote`, `pre`는 기본적으로 블록 방식으로 표시된다.

```html
<div>첫 번째 영역</div>
<div>두 번째 영역</div>
```

- 두 `div`는 위아래로 배치된다.
- 일반적인 문서 흐름에서 너비를 별도로 지정하지 않은 블록 박스는 부모의 사용 가능한 너비를 채운다.
- 텍스트가 짧아도 박스의 너비가 텍스트 길이에 맞춰 줄어드는 것은 아니다.
- `width`, `height`로 크기를 지정할 수 있다. 너비를 줄여도 다음 블록이 자동으로 옆에 배치되지는 않는다.
- 제목과 문단의 기본 여백은 각 요소에 적용된 스타일이다. 모든 블록 요소가 같은 여백을 갖는 것은 아니다.

### 인라인 요소

대표적으로 `span`, `strong`, `em`, `b`, `i`, `code`, `a`는 기본적으로 인라인 방식으로 표시된다.

```html
<p>저는 <strong>HTML</strong>과 <em>CSS</em>를 배우고 있습니다.</p>
```

- `strong`과 `em`은 문장의 흐름 안에 배치된다.
- 배경색 등을 지정하면 해당 텍스트가 차지하는 영역을 중심으로 표시된다.
- 공간이 부족하면 텍스트가 다음 줄로 이어질 수 있다. 인라인이라고 항상 한 줄에만 표시되는 것은 아니다.
- `span` 같은 일반적인 인라인 요소에는 `width`, `height`가 적용되지 않는다.
- 다만 `img`처럼 외부 이미지로 내용을 대체하는 요소는 인라인 배치에서도 너비와 높이를 지정할 수 있다.

### 두 방식 비교하기

다음 표는 Flexbox나 Grid 등을 적용하지 않은 일반적인 문서 흐름을 기준으로 한다.

| 구분 | 블록 | 인라인 |
| --- | --- | --- |
| 배치 | 새 줄에 배치 | 텍스트와 같은 줄의 흐름에 배치 |
| 기본 너비 | 보통 부모의 사용 가능한 너비를 채움 | 내용에 따라 차지하는 영역이 결정됨 |
| `width`, `height` | 지정 가능 | 일반 텍스트 인라인 요소에는 적용되지 않음 |
| 대표 예 | `div`, `p`, `h1`, `pre` | `span`, `strong`, `em`, `code` |

### `div`와 `span`

두 요소는 자체적으로 특별한 의미를 부여하지 않고 내용을 묶는 데 사용한다. 기본 배치 방식은 서로 다르다.

```html
<div>
  <h2>자기소개</h2>
  <p>저의 이름은 <span style="color: royalblue;">홍길동</span>입니다.</p>
</div>
```

- `div`는 제목과 문단을 하나의 영역으로 묶는다.
- `span`은 문장 안에서 이름 부분만 묶는다.
- `span` 자체가 파란색을 의미하는 것은 아니다. 색상은 `style` 속성에 작성한 CSS가 지정한다.
- 문단이면 `p`, 중요한 내용이면 `strong`처럼 목적에 맞는 요소가 있을 때는 그 요소를 먼저 선택한다.

### CSS로 배치 방식 변경하기

```html
<span style="display: block;">블록으로 표시하는 첫 번째 span</span>
<span style="display: block;">블록으로 표시하는 두 번째 span</span>

<div style="display: inline;">인라인으로 표시하는 첫 번째 div</div>
<div style="display: inline;">인라인으로 표시하는 두 번째 div</div>
```

- `display: block`은 블록 방식으로, `display: inline`은 인라인 방식으로 배치한다.
- 배치 방식을 바꿔도 태그의 의미와 HTML 중첩 규칙은 바뀌지 않는다.
- `display: inline-block`을 사용하면 텍스트 흐름 안에 배치하면서 `width`, `height`도 지정할 수 있다.

```html
<p>
  선택 항목:
  <span style="display: inline-block; width: 100px; background: gold;">HTML</span>
  <span style="display: inline-block; width: 100px; background: lightblue;">CSS</span>
</p>
```

### 배치 방식과 중첩 규칙 구분하기

**“블록 안에는 무엇이든 넣을 수 있다” 또는 “인라인 안에는 블록을 절대 넣을 수 없다”로 외우지 않는다.** 자식으로 허용되는 내용은 각 HTML 요소의 규칙에 따라 다르다.

예를 들어 `div` 안에는 문단을 넣을 수 있다.

```html
<div>
  <p>첫 번째 문단</p>
  <p>두 번째 문단</p>
</div>
```

그러나 `p` 안에 `div`나 또 다른 `p`를 넣는 것은 올바르지 않다.

```html
<!-- 잘못된 예 -->
<p>문단 시작 <div>별도 영역</div> 문단 끝</p>
```

브라우저는 위 코드에서 `div`가 시작되기 전에 `p`를 자동으로 닫는 등 구조를 보정한다. 따라서 작성한 코드와 개발자 도구에서 확인하는 요소 구조가 달라질 수 있다. `div`에 `display: inline`을 지정해도 잘못된 중첩이 해결되지는 않는다.

```html
<!-- 올바른 예 -->
<p>문단 시작</p>
<div>별도 영역</div>
<p>문단 끝</p>
```
