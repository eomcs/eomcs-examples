# HTML 프로그래밍

## 개발 환경 구성

- VS Code (Microsoft)
  - 웹 개발을 위한 무료 소스 코드 편집기
- Live Preview 확장 (ms-vscode.live-server, Microsoft)
  - 실시간으로 HTML, CSS, JavaScript 변경 사항을 브라우저에서 확인할 수 있는 VS Code 확장 기능

- 3장. 목록과 하이퍼링크 
- 4장. 이미지와 미디어 
- 5장. 의미 있는 페이지 구성 
- 6장. 표로 데이터 표현하기

- 8장. 웹 서버 구축과 배포
