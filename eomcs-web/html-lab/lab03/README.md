# 목록과 하이퍼링크

- 순서 없는 목록: `ul`, `li`
- 순서 있는 목록: `ol`, `li`
- 설명 목록: `dl`, `dt`, `dd`
- 하이퍼링크: `a`, `href`, `target`
- 절대 URL과 상대 경로
- 페이지 내부 이동: 프래그먼트와 `id`
- 소개·시간표·문의 페이지를 연결하는 메뉴 구성

## 1. 순서 없는 목록: `ul`, `li`

### 목록으로 표현하기

관심 분야, 준비물처럼 여러 항목을 묶어 표현할 때 목록을 사용한다. 항목의 순서가 의미에 영향을 주지 않으면 `ul`을 사용한다.

- `ul`은 unordered list의 약자로 순서 없는 목록을 나타낸다.
- `li`는 list item의 약자로 목록의 각 항목을 나타낸다.
- 브라우저는 기본적으로 각 항목 앞에 글머리 기호를 표시한다.

```html
<h2>관심 분야</h2>
<ul>
  <li>웹 개발</li>
  <li>사진 촬영</li>
  <li>여행</li>
</ul>
```

`ul`이 목록 전체를 묶고, 각 항목의 내용은 `li` 안에 작성한다. 글머리 기호를 직접 입력하거나 문단마다 `br`을 넣어 목록을 흉내 내지 않는다. 목록 요소를 사용하면 브라우저와 화면 낭독기가 목록의 구조를 파악할 수 있다.

### 실습: 관심 분야 목록 작성하기

2. 문서 언어를 `ko`, 문서 제목을 `나의 관심 분야`로 수정한다.
3. `body`에 `h1`과 위 예제의 목록을 작성한다.
4. 항목을 자신의 관심 분야로 바꾸고 하나를 추가한다.
5. Live Preview에서 항목의 배치와 글머리 기호를 확인한다.

다음 Emmet 약어로 세 항목의 틀을 만들 수도 있다.

```text
ul>li{관심 분야 $}*3
```

## 2. 순서 있는 목록: `ol`, `li`

### 순서가 중요한 내용 표현하기

실습 절차, 요리 순서처럼 항목의 순서가 의미를 가지면 `ol`을 사용한다. `ol`은 ordered list의 약자이며, 각 항목은 `li`로 작성한다.

```html
<h2>HTML 실습 순서</h2>
<ol>
  <li>VS Code에서 실습 폴더를 연다.</li>
  <li>HTML 파일을 작성한다.</li>
  <li>파일을 저장한다.</li>
  <li>Live Preview에서 결과를 확인한다.</li>
</ol>
```

브라우저가 번호를 표시하므로 내용에 `1.`, `2.`를 직접 입력하지 않는다. 항목을 추가하거나 삭제하면 번호도 그에 맞게 표시된다.

### 시작 번호와 번호 형식

| 속성 | 작성 위치 | 의미 | 예 |
| --- | --- | --- | --- |
| `start` | `ol` | 시작 번호 지정 | `<ol start="3">` |
| `reversed` | `ol` | 번호를 내림차순으로 표시 | `<ol reversed>` |
| `type` | `ol` | 번호 형식 지정 | `<ol type="A">` |
| `value` | `li` | 해당 항목의 번호 지정 | `<li value="5">` |

`type`에는 `1`, `a`, `A`, `i`, `I` 등을 사용할 수 있다. `reversed`는 불리언 속성으로, 작성되어 있으면 적용된다. `reversed="false"`로 작성해도 꺼지는 것이 아니므로 사용하지 않을 때는 속성을 제거한다.

```html
<ol start="3">
  <li>이미지를 추가한다.</li>
  <li>하이퍼링크를 연결한다.</li>
  <li>브라우저에서 테스트한다.</li>
</ol>
```

위 목록은 3, 4, 5부터 표시된다. `start` 값은 문자 형식을 사용하더라도 정수로 작성한다. 예를 들어 `type="A" start="3"`은 C부터 시작한다.

3. `start="3"`, `type="A"`, `reversed`를 하나씩 적용하며 차이를 확인한다.

## 3. 중첩 목록

### 목록 항목 안에 하위 목록 넣기

하나의 항목을 다시 여러 항목으로 나눌 때 목록을 중첩한다. **하위 목록은 상위 목록의 `li` 안에 작성한다.**

```html
<h2>학습 분야</h2>
<ul>
  <li>
    웹 개발
    <ol>
      <li>HTML로 구조 만들기</li>
      <li>CSS로 꾸미기</li>
      <li>JavaScript로 동작 추가하기</li>
    </ol>
  </li>
  <li>사진 촬영</li>
</ul>
```

이 예제는 순서 없는 관심 분야 목록 안에 순서 있는 학습 절차를 넣었다.

```text
관심 분야 (ul)
├── 웹 개발 (li)
│   └── 학습 절차 (ol)
│       ├── HTML로 구조 만들기 (li)
│       ├── CSS로 꾸미기 (li)
│       └── JavaScript로 동작 추가하기 (li)
└── 사진 촬영 (li)
```

다음처럼 하위 목록을 `li` 바깥에 작성하지 않는다.

```html
<!-- 잘못된 예 -->
<ul>
  <li>웹 개발</li>
  <ol>
    <li>HTML로 구조 만들기</li>
  </ol>
</ul>
```

### 실습: 하위 관심 분야 추가하기

1. `exam01.html`의 관심 분야 중 하나에 하위 목록을 추가한다.
2. 하위 목록 전체가 해당 항목의 시작 태그 `<li>`와 종료 태그 `</li>` 사이에 있는지 확인한다.
3. 문서 서식 지정을 실행하여 들여쓰기를 정리하고 포함 관계를 읽어 본다.

## 4. 설명 목록: `dl`, `dt`, `dd`

### 이름과 설명을 짝지어 표현하기

용어와 정의, 항목 이름과 값처럼 서로 대응하는 내용을 표현할 때 설명 목록을 사용한다.

| 요소 | 역할 |
| --- | --- |
| `dl` | 설명 목록 전체를 묶음 |
| `dt` | 용어나 항목 이름 |
| `dd` | 해당 용어의 설명이나 항목의 값 |

```html
<h2>웹 개발 용어</h2>
<dl>
  <dt>HTML</dt>
  <dd>웹 문서의 구조와 의미를 표현하는 마크업 언어</dd>

  <dt>CSS</dt>
  <dd>웹 문서의 색상, 크기, 배치 등을 지정하는 스타일 시트 언어</dd>

  <dt>JavaScript</dt>
  <dd>웹 페이지에 동작을 추가할 수 있는 프로그래밍 언어</dd>
</dl>
```

- `dt`와 `dd`는 위 예제에서 `dl`의 자식 요소이다. `dd`를 `dt` 안에 넣지 않는다.
- 한 항목에 여러 설명이 필요하면 `dd`를 여러 개 작성할 수도 있다.
- 기본 스타일에서 `dd`에 들여쓰기가 적용될 수 있지만, 단순히 여백을 만들기 위한 태그는 아니다.

3. 하나의 관심 분야 이름에 설명 두 개를 `dd` 두 개로 작성한다.
4. `ul`, `ol`, `dl`의 용도를 비교한다.

## 5. 하이퍼링크: `a`

### 다른 자료로 이동하기

`a`는 anchor를 뜻하며, `href` 속성으로 이동할 주소를 지정하면 하이퍼링크를 만든다.

```html
<a href="https://developer.mozilla.org/ko/docs/Web/HTML">HTML 참고 문서</a>
```

| 구성 | 의미 |
| --- | --- |
| `a` | 링크를 만드는 요소 |
| `href` | 이동할 URL을 지정하는 속성 |
| `HTML 참고 문서` | 사용자가 읽고 선택할 링크 텍스트 |

- 링크를 클릭하면 기본적으로 현재 탭에서 대상 자료로 이동한다.
- 일반적인 브라우저에서 `Tab` 키로 링크에 초점을 옮기고 `Enter` 키로 이동할 수 있다.
- 링크 색상과 밑줄은 기본 스타일이며 CSS로 바꿀 수 있다.
- `href`가 없는 `a`는 이동할 대상이 있는 하이퍼링크가 아니다.
- 링크 안에 또 다른 링크를 중첩하지 않는다.

### 새 탭 또는 창에서 열기

```html
<a href="https://developer.mozilla.org/ko/docs/Web/HTML"
   target="_blank"
   rel="noopener">HTML 참고 문서 (새 탭 또는 창)</a>
```

- `target="_blank"`는 새 탐색 창을 요청한다. 실제로 새 탭이나 창 중 어디에 열리는지는 브라우저 설정 등에 따라 달라진다.
- `rel="noopener"`는 열린 페이지가 `window.opener`를 통해 원래 페이지를 제어하지 못하도록 한다.
- 새 창이 열리는 링크에는 위 예제처럼 동작을 미리 알리는 문구를 제공한다.

### 링크 텍스트 작성하기

```html
<!-- 목적을 알기 어려운 링크 -->
<a href="schedule.html">여기를 클릭</a>

<!-- 목적을 알 수 있는 링크 -->
<a href="schedule.html">주간 학습 시간표 보기</a>
```

링크 텍스트만 읽어도 이동할 내용을 예상할 수 있게 작성한다. 파일 경로가 정확해도 대상 파일이 없으면 원하는 페이지를 열 수 없다. `schedule.html`은 마지막 종합 실습에서 작성한다.

## 6. 절대 URL과 상대 경로

### URL이 해석되는 기준

다음 폴더 구조와 현재 페이지 주소를 가정한다. Live Preview는 `html-lab`을 서버 루트로 사용한다.

```text
html-lab/
├── lab02/
│   └── exam01.html
└── lab03/
    ├── index.html       ← 현재 페이지
    ├── schedule.html
    └── contact.html
```

```text
http://localhost:3000/lab03/index.html
```

| 방식 | `href` 값 | 해석되는 주소 |
| --- | --- | --- |
| 절대 URL | `https://example.com/guide.html` | 지정한 외부 사이트의 주소 |
| 같은 폴더의 상대 경로 | `schedule.html` | `http://localhost:3000/lab03/schedule.html` |
| 현재 폴더를 명시한 상대 경로 | `./contact.html` | `http://localhost:3000/lab03/contact.html` |
| 상위 폴더를 거치는 상대 경로 | `../lab02/exam01.html` | `http://localhost:3000/lab02/exam01.html` |
| 사이트 루트 기준 경로 | `/lab02/exam01.html` | `http://localhost:3000/lab02/exam01.html` |

- 절대 URL은 스킴과 호스트 등을 포함하므로 전체 주소를 알 수 있다.
- 상대 경로는 현재 문서의 URL을 기준으로 해석된다. 이 교재에서는 기준 URL을 바꾸는 `base` 요소를 사용하지 않는다.
- `./`는 현재 폴더, `../`는 상위 폴더를 뜻한다.
- `/`로 시작하면 현재 사이트의 루트를 기준으로 한다. 운영체제의 디스크 루트를 뜻하는 것은 아니다.
- 예제의 `3000`은 실습용 포트이다. 실제 접속은 Live Preview에 표시된 포트를 사용한다.

### 경로를 작성할 때 주의할 점

- Windows에서도 URL의 경로 구분자는 역슬래시(`\`)가 아니라 슬래시(`/`)를 사용한다.
- `C:\Users\...` 같은 개인 컴퓨터의 파일 경로를 웹 링크로 작성하지 않는다.
- 파일 이름의 대소문자를 정확히 맞춘다. 서버 환경에 따라 `Index.html`과 `index.html`은 다른 파일일 수 있다.
- 상대 경로는 파일의 위치를 옮기면 의미가 달라질 수 있다.
- 로컬 페이지에 `localhost`를 포함한 절대 URL을 고정하면 다른 컴퓨터에서도 그 컴퓨터 자신을 가리킨다. 같은 사이트의 페이지 연결에는 상대 경로를 활용한다.

### 실습: 이동 주소 예상하기

현재 주소가 `http://localhost:3000/lab03/index.html`일 때 다음 링크의 최종 주소를 적어 본다.

```html
<a href="exam01.html">관심 분야 실습</a>
<a href="../lab02/exam02.html">제목과 문단 실습</a>
<a href="/lab03/exam03.html">설명 목록 실습</a>
```

위 코드를 `index.html`의 기본 구조 안에 넣고 링크를 선택하여 주소창의 결과와 비교한다. 대상 파일은 앞선 실습에서 작성되어 있어야 한다.

## 7. 페이지 내부 이동: `id`와 프래그먼트

### 같은 페이지의 특정 위치로 이동하기

제목 등에 고유한 `id`를 지정하고, 링크의 `href`에 `#id값`을 작성한다.

```html
<h1 id="top">나의 학습 소개</h1>
<ul>
  <li><a href="#interests">관심 분야</a></li>
  <li><a href="#goals">학습 목표</a></li>
</ul>

<h2 id="interests">관심 분야</h2>
<p>웹 개발과 사진 촬영에 관심이 있습니다.</p>

<h2 id="goals">학습 목표</h2>
<p>나의 웹사이트를 직접 만들고 싶습니다.</p>

<p><a href="#top">맨 위로 이동</a></p>
```

- `id="goals"`는 이동 대상 요소의 이름을 지정한다.
- `href="#goals"`는 해당 요소로 이동하는 링크를 만든다.
- `id`에는 `#`을 넣지 않고, 링크에서 프래그먼트를 시작할 때 `#`을 붙인다.
- `id`는 같은 문서 안에서 중복하지 않으며, 링크와 대소문자까지 맞춘다.
- 같은 문서의 프래그먼트 이동은 보통 문서를 다시 내려받지 않고 브라우저가 처리한다.
- 문서가 짧거나 대상이 이미 화면에 보이면 이동해도 큰 변화가 없을 수 있다.

### 다른 페이지의 특정 위치로 이동하기

```html
<a href="index.html#goals">자기소개 페이지의 학습 목표 보기</a>
```

`index.html`을 연 뒤 그 문서에서 `id="goals"`인 요소로 이동한다. 프래그먼트 `#goals`는 HTTP 요청에 포함되지 않고 브라우저에서 처리한다.

### 실습: 목차 만들기

1. `lab03/exam05.html`에 위 예제의 기본 구조와 본문을 작성한다.
2. 각 주제 아래에 설명 문단을 여러 개 추가하거나 브라우저 창의 높이를 줄여 스크롤이 생기도록 한다.
3. 목차를 선택하여 대상 위치와 주소창의 `#interests`, `#goals`를 확인한다.
4. `#top` 링크로 맨 위로 이동한다.

## 8. 종합 실습: 세 페이지를 연결하는 메뉴

### 실습 목표와 파일 구성

목록과 링크를 사용하여 소개·시간표·문의 페이지를 연결한다. 시간표는 이번에는 목록으로, 문의 정보는 설명 목록으로 작성한다. 표와 입력 폼은 이후 수업에서 배운다.

```text
lab03/
├── index.html       # 소개와 학습 목표
├── schedule.html    # 학습 일정
└── contact.html     # 문의 안내
```

세 파일 모두 Emmet의 `!`로 기본 구조를 만들고 `lang="ko"`와 적절한 `title`을 지정한다. `index.html`을 앞서 만들었다면 기본 구조를 유지하고 본문을 아래 내용으로 정리한다.

### 1) 공통 메뉴 작성하기

세 페이지의 `body` 맨 앞에 다음 메뉴를 작성한다. 파일들이 같은 폴더에 있으므로 파일 이름만으로 연결할 수 있다.

```html
<ul>
  <li><a href="index.html">소개</a></li>
  <li><a href="schedule.html">학습 시간표</a></li>
  <li><a href="contact.html">문의 안내</a></li>
</ul>
```

### 2) 소개 페이지: `index.html`

공통 메뉴 아래에 다음 내용을 작성한다.

```html
<h1>홍길동의 학습 소개</h1>
<p>안녕하세요. HTML을 배우고 있는 홍길동입니다.</p>
<p><a href="#goals">학습 목표로 이동</a></p>

<h2>관심 분야</h2>
<ul>
  <li>
    웹 개발
    <ul>
      <li>HTML 문서 작성</li>
      <li>CSS로 페이지 꾸미기</li>
    </ul>
  </li>
  <li>사진 촬영</li>
</ul>

<h2 id="goals">학습 목표</h2>
<ol>
  <li>의미에 맞는 HTML 요소를 선택한다.</li>
  <li>페이지를 하이퍼링크로 연결한다.</li>
  <li>브라우저에서 동작을 확인한다.</li>
</ol>
```

### 3) 시간표 페이지: `schedule.html`

공통 메뉴 아래에 다음 내용을 작성한다.

```html
<h1>주간 학습 시간표</h1>
<ol>
  <li>월요일: HTML 기본 구조와 텍스트</li>
  <li>화요일: 목록과 하이퍼링크</li>
  <li>수요일: 이미지와 미디어</li>
</ol>
<p><a href="index.html#goals">학습 목표 다시 보기</a></p>
```

### 4) 문의 페이지: `contact.html`

공통 메뉴 아래에 다음 내용을 작성한다.

```html
<h1>문의 안내</h1>
<dl>
  <dt>담당자</dt>
  <dd>홍길동</dd>

  <dt>문의 방법</dt>
  <dd>수업 시간에 강사에게 질문해 주세요.</dd>

  <dt>문의 시 준비할 내용</dt>
  <dd>실습 파일 이름, 실행한 주소, 오류 메시지를 정리해 주세요.</dd>
</dl>
```

### 5) 동작 점검하기

- 세 페이지 모두 공통 메뉴로 서로 이동할 수 있는지 확인한다.
- 브라우저 탭의 제목과 본문의 `h1`이 각 페이지 내용에 맞는지 확인한다.
- `schedule.html`에서 `index.html#goals`로 이동할 수 있는지 확인한다.
- `Tab`과 `Enter` 키로 메뉴를 사용할 수 있는지 확인한다.
- 링크가 열리지 않으면 주소창의 경로와 실제 파일 이름·위치를 비교한다.
- 중첩 목록이 `li` 안에 있고, 설명 목록의 `dt`와 `dd`가 짝을 이루는지 확인한다.
